# R26 performance measurements

R26 bounds work that grows with persisted attempts or practice-session length.
Measurements were taken on 2026-09-19 on an arm64 development machine with
Flutter 3.47.4 and Dart 3.13.3. They are comparative microbenchmarks, not device
latency guarantees.

## Results

| Path | Representative data | Before | After | Change |
| --- | --- | ---: | ---: | ---: |
| History database read | 50,000 attempts; first 100 requested | 86,921 µs median | 6,279 µs median | 13.8× faster |
| Filtered navigation wrap | 4,475 questions; 2,237 eligible | 48,426 µs median | 59 µs median | 820.8× faster |

The history benchmark compares materializing every ordered attempt with reading
the 101 rows required to return a 100-row prefix plus `hasMore`. Both queries use
the production timestamp-descending, insertion-ID-descending ordering. The app
starts with 100 attempts and grows the same prefix by 100 on request, avoiding
offset drift when a new attempt is inserted.

The navigation benchmark reproduces the old wraparound case: every remaining
question precedes the current question, so `indexOf` rescanned the catalog for
each candidate. The replacement performs one circular eligibility scan and
preserves the same selection and wrap behavior.

Run the retained benchmarks from their package directories:

```sh
cd packages/pm_persistence
flutter test --no-pub tool/benchmark_r26_history.dart -r expanded

cd ../../pm_app
flutter test --no-pub tool/benchmark_r26_navigation.dart -r expanded
```

## Costs deliberately left unchanged

- `HomeLoaded` already prepares `PracticeQuestionSummary` once per immutable
  state, so its getters no longer reconstruct question-code sets.
- Drawer navigation remains available only for the 30-question simulacro. Its
  eager keys preserve current-tile scrolling, and replacing that bounded path
  would add complexity without a demonstrated gain.

Revisit the drawer only if navigation is enabled for materially larger sessions,
and rerun these benchmarks after changing history ordering or page size.
